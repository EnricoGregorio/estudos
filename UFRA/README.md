## 📌 Sobre este repositório

Este espaço é dedicado ao armazenamento e versionamento de todos os trabalhos práticos, laboratórios e projetos desenvolvidos durante a minha graduação na **UFRA**. 

O objetivo aqui não é apenas guardar código, mas registrar uma **trajetória de amadurecimento técnico**: sair dos conceitos fundamentais da computação e avançar rumo à engenharia de software e modelagem de dados.
